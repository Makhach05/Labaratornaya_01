## Лабораторная работа 1
### Решенные задачи:
1. A+B (Сумма двух чисел) - программа складывает два введенных числа
2. Прямоугольный треугольник - вычисляет гипотенузу, площадь и периметр по двум катетам
3. Сумма цифр трехзначного числа - находит сумму цифр трехзначного числа

### Описание решения:
Все задачи реализованы на языке C# в среде разработки JetBrains Rider. Каждая задача находится в отдельном файле в папке `Lab1/`.

### Как запустить программу:
1. Установите .NET SDK 6.0 или выше
2. Откройте терминал в папке проекта
3. Выполните команду: `dotnet run`
