## Выполненные задания

### Задача 1: Проверка треугольника по углам
Программа запрашивает два угла треугольника, вычисляет третий угол и определяет:
- Существует ли треугольник
- Тип треугольника (прямоугольный, остроугольный, тупоугольный)

### Задача 2: Ближайшая точка к началу координат
Программа сравнивает две точки на плоскости и определяет, какая из них ближе к началу координат (0, 0).

### Задача 3: Положение точки на плоскости
Программа определяет положение точки:
- В начале координат
- На оси X или Y
- В одном из 4-х координатных углов

### Задача 4: Принадлежность точки окружности
Программа проверяет, где находится точка относительно окружности с центром в (0, 0):
- Внутри окружности
- На окружности
- Снаружи окружности

### Задача 5: Условное возведение в степень
Программа обрабатывает три числа:
- Неотрицательные числа возводит в квадрат
- Отрицательные числа возводит в 4-ю степень

## Используемые операторы ветвления
- Оператор `if-else if-else` (задачи 1-4)
- Тернарный оператор `? :` (задача 5)
- Вложенные условия (задача 3)
- Сравнение чисел с плавающей точкой с погрешностью
