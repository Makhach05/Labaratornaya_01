### Решенные задачи:
1. **Сумма чисел от 1 до N** - программа вычисляет сумму всех чисел от 1 до заданного числа N с использованием цикла `for`
2. **Числа Фибоначчи** - выводит указанное количество чисел последовательности Фибоначчи с использованием цикла `while`
3. **Угадай число** - интерактивная игра, где компьютер загадывает число от 1 до 100, а пользователь пытается его угадать с использованием цикла `do-while`
4. **Прямоугольник из символов** - рисует прямоугольник заданного размера из указанного символа с использованием вложенных циклов

### Описание решения:
Все задачи реализованы на языке C# в среде разработки JetBrains Rider. Каждая задача находится в отдельном файле в папке Lab4/. Реализовано меню для выбора задач и возможность запуска всех задач последовательно.

### Как запустить программу:
1. Установите .NET SDK 6.0 или выше
2. Откройте терминал в папке проекта
3. Выполните команду: `dotnet run`
4. Выберите номер задачи в меню
